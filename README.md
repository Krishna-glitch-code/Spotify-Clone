# Spotify Clone 🎵

A frontend UI clone of Spotify built using only HTML and CSS.  
This project focuses on layout, styling, and responsive design.

## Features
- Spotify-inspired user interface  
- Clean and structured layout  
- Responsive design for different screen sizes  
- Pure HTML & CSS (no JavaScript)

## Tech Stack
- HTML5  
- CSS3  

## Purpose
Built to practice HTML structure, CSS styling, flexbox/grid, and responsive UI design.
